# تقویم (taqvim): کتابخانهٔ دقیق تاریخ شمسی برای جاوااسکریپت، تایپ‌اسکریپت و پایتون

تبدیل تاریخ شمسی و میلادی، خواندن تاریخ‌هایی که کاربر فارسی‌زبان تایپ می‌کند، نمایش فارسی، دری و انگلیسی، حساب درست ماه و سال، و ساعت درست تهران؛ با یک رفتار یکسان در دو زبان.

[English](README.md) · [گزارش دقت و مقایسه](docs/ACCURACY.md) · [جدول نوروز سال ۱ تا ۲۹۹۹](reference/nowruz.csv)

## چرا یک کتابخانهٔ جدید؟

کتابخانه‌های موجود هر کدام بخشی از کار را حل می‌کنند و چند تا از آن‌ها باگ‌های جدی دارند ([گزارش کامل با روش آزمون](docs/ACCURACY.md)):

* **سال کبیسهٔ اشتباه:** کتابخانه‌هایی که با فرمول ریاضی کار می‌کنند از تقویم واقعی فاصله می‌گیرند. مثلاً کتابخانهٔ پایتونی `khayyam` نوروز ۱۴۰۴ را ۲۰ مارس ۲۰۲۵ می‌داند، در حالی که ۲۱ مارس بود. یعنی همهٔ روزهای سال ۱۴۰۴ در آن یک روز جابه‌جاست. `persian-date` هم برای سال ۱۳۴۲ اشتباه می‌کند. تقویم از **جدول نجومی اعتدال بهاری** برای سال‌های ۱ تا ۲۹۹۹ استفاده می‌کند که با داده‌های JPL ناسا هم بررسی شده است.
* **تاریخ ناموجود:** ۳۰ اسفند ۱۴۰۴ وجود ندارد. چند کتابخانه آن را بی‌صدا به ۱ فروردین ۱۴۰۵ تبدیل می‌کنند یا معتبر می‌دانند. تقویم آن را **رد می‌کند** و دلیلش را می‌گوید.
* **ارقام و صفحه‌کلید فارسی:** `۱۴۰۴/۰۱/۱۵` در بعضی کتابخانه‌ها خطا می‌دهد یا سال ۶۲۱ برمی‌گرداند. تقویم ارقام فارسی و عربی، «ي» و «ك» عربی، نیم‌فاصله، نام ماه‌ها، روز هفته و «ه.ش» را می‌فهمد.
* **ساعت تهران:** ساعت تابستانی ایران از ۱۴۰۱ لغو شد، ولی دستگاه‌هایی که اطلاعات منطقهٔ زمانی‌شان قدیمی است هنوز یک ساعت جلو می‌روند. تقویم تاریخچهٔ منطقهٔ زمانی تهران را درون خودش دارد.
* **یک قاعده برای دو زبان:** معمولاً فرانت‌اند و بک‌اند دو کتابخانهٔ متفاوت با قواعد متفاوت دارند. تقویم یک مشخصه و یک مجموعه آزمون مشترک دارد.

## نمونه

</div>

```ts
import { JalaliDate } from 'taqvim';

const d = new JalaliDate(1404, 1, 15);
d.format('dddd D MMMM YYYY');      // 'جمعه ۱۵ فروردین ۱۴۰۴'
d.toISODate();                     // '2025-04-04'
d.addMonths(1).toString();         // '1404/02/15'
JalaliDate.parse('۱۵ فروردین ۱۴۰۴');
JalaliDate.today();                // امروز به وقت تهران
```

```python
from taqvim import JalaliDate

d = JalaliDate(1404, 1, 15)
d.format('dddd D MMMM YYYY')       # 'جمعه ۱۵ فروردین ۱۴۰۴'
d.to_date()                        # datetime.date(2025, 4, 4)
JalaliDate.parse('۱۵ فروردین ۱۴۰۴')
```

## امکانات

* تبدیل شمسی ↔ میلادی، کبیسه، تعداد روزهای ماه، اعتبارسنجی دقیق
* کلاس تغییرناپذیر `JalaliDate` با جمع روز، هفته، ماه و سال (۳۱ شهریور + ۱ ماه = ۳۰ مهر)
* قالب‌بندی با نام ماه‌های ایران (فروردین…) و افغانستان (حمل، ثور…) یا انگلیسی، با ارقام فارسی، عربی یا لاتین
* خواندن تاریخ از متن آزاد فارسی، دری و انگلیسی
* ساعت درست تهران بدون وابستگی به سیستم‌عامل
* تعطیلات رسمی ثابت شمسی و محاسبهٔ روز کاری. تعطیلات قمری چون هر سال با رؤیت ماه اعلام می‌شوند، از بیرون داده می‌شوند.
* بدون هیچ وابستگی؛ نسخهٔ جاوااسکریپت ۷٫۴ کیلوبایت

## محدودیت‌ها

* بازهٔ پشتیبانی: سال ۱ تا ۲۹۹۹ شمسی
* چند سال از نظر نجومی مرزی هستند، یعنی تحویل سال نزدیک ظهر است. نزدیک‌ترینشان سال ۱۴۷۰ است. این سال‌ها با `isUncertainYear` مشخص می‌شوند و پنهان نمی‌مانند.
